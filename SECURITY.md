# Security Policy

## Reporting a vulnerability

Please do not publish credentials, private keys, tokens, passwords or other sensitive information in a public issue.

For security-sensitive reports, use the repository's private security reporting mechanism if enabled by the repository owner. If private reporting is not available, contact the repository maintainer before public disclosure.

## Scope

This project controls privileged Timeshift operations through Cockpit. Security reports involving privilege escalation, command injection, unsafe input handling, or unintended privileged execution are especially important.
