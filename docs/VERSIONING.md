# Versioning

Convenção de versionamento para Cockpit Timeshift.

## Nomes de versão

```
v0.1.0-beta
    primeira versão funcional aprovada

v0.1.0-beta-dev
    linha de desenvolvimento correspondente

v0.2.0-beta
    próxima versão funcional aprovada

v1.0.0
    primeira release considerada estável
```
